# Шеврони · Фінанси — дашборд для Google Таблиці

Файли:
- **Code.gs** — Apps Script: будує аркуш «Дашборд» (KPI, MoM-динаміка, структура витрат,
  бюджети категорій, health score, діаграми) і додає меню «⚡ Шеврони» з формою вводу.
- **Form.html** — бічна панель «Нова операція» (тип, дата, сума, категорії-плитки, примітка).
- **app.html** — інтерактивний макет-еталон дизайну (відкривається в браузері).

## Встановлення
1. Відкрийте таблицю → **Розширення → Apps Script**
2. Вміст `Code.gs` замініть файлом **Code.gs**
3. **Файл → Створити → HTML**, назва `Form`, вставте вміст **Form.html**
4. Збережіть (Ctrl+S) і оновіть сторінку таблиці
5. Меню **⚡ Шеврони → 🔄 Перебудувати дашборд** (перший запуск попросить дозволи)
6. Додавання записів: **⚡ Шеврони → ➕ Додати операцію**

Ліміти бюджетів редагуються на аркуші «Довідник», колонки D:E.
Джерело даних — аркуш «Журнал»; дашборд оновлюється формулами автоматично.
